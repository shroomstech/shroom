■ SquareOS

codename: Kelperus

What is SquareOS?

SquareOS is an x86_64 operating system written from scratch in C. It does not use the Linux, Windows NT, or Darwin kernels. The goal is to be lightweight, approachable, and easy to understand.

The project is built with AI assistance and identifies this workflow as Vibecoded OSDev (V-OSDev) — honest about what AI helped with and what actually works.

What works?

  • Kernel: GDT, TSS, IDT, syscall (int 0x80), Ring-3 usermode, 2 MB heap, ACPI, E1000
  • Shell: 30+ commands (help, fastfetch, tglgears, usrspacestart, gldemo, gears, ...)
  • SquareDE: Win95-style desktop with movable windows, start menu, taskbar
  • SquareGL: Minimal software OpenGL 1.x for the kernel
  • TinyGL: Full BoredOS TinyGL OpenGL 1.1 (z-buffer, lighting, textures) ported into the kernel
  • klibc: Freestanding C library (string, ctype, errno, stdlib, stdio, math, time, setjmp)

What is planned?

  • PMM / VMM — physical memory manager, per-process paging
  • VFS + ramfs + /dev
  • ELF loader + execve + userspace processes
  • Threads (pthread, futex)
  • AF_UNIX sockets + IPC
  • Port BoredOS Nova compositor against klibc + SquareOS syscalls

How to build

git clone https://github.com/KelpOS-Project/SquareOS.git
cd SquareOS
make

Requires: gcc, binutils, grub2-mkrescue, xorriso, qemu-system-x86. The kernel links to 290 KB and boots in QEMU via GRUB Multiboot v1.
