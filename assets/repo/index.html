Repository Page

Welcome to the Repository Page! Here is a Tutorial on How to add the Curse Repository to your Current Arch installation

follow these steps
1. sudo nano /etc/pacman.conf
2. add this section below
[curse]
SigLevel = Optional TrustAll
Server = https://raw.githubusercontent.com/shroomstech/curse-packages/main/$arch
3. sudo pacman -Syu
4. sudo pacman -Sl curse
and there you have it the Curse Repository
